## Roast Button

An interactive prank web game featuring a button that constantly tries to escape while roasting the player.

## Overview

This project challenges the user to catch a moving button that reacts whenever the cursor approaches it. The button changes its position, appearance, and messages while tracking the player's performance.

## Behaviors
Evasive Movement: The button moves to random positions across the screen when the cursor reaches it.
Dynamic Difficulty: The button starts difficult to catch and gradually becomes easier as the number of escapes increases.
Random Roasts: A new funny roast is displayed whenever the button escapes.
Dynamic Appearance: The button randomly changes its color, size, and text while moving.
Escape Tracking: Keeps track of how many times the button successfully escapes the player.
Timer: Measures how long it takes the player to finally catch the button.
Victory Reaction: Successfully catching the button displays a funny reaction GIF along with a final roast and game statistics.
Play Again: The player can restart the prank and attempt to catch the button again.
